These are placeholders. To use real recordings, replace the files (or add more variants, e.g.
`shot_6.wav`) and add a row per file with its source URL, author and license. Any of
`.wav .aif .aiff .caf .mp3 .m4a` work; files are converted to 48 kHz mono at launch and leading
silence is trimmed automatically.
